## 🇺🇸 English

### Overview
TAVARDT Pulse is a lightweight, open source monitoring utility designed for corporate digital assets. It allows engineers to monitor service uptime and receive instant alerts via Discord or Slack webhooks. This tool is part of the TAVARDT Elite Infrastructure suite, focusing on business continuity and reliability.

### Key Features
* HTTP Status Monitoring: Real time health checks for any web service.
* Instant Alerting: Automatic notifications to your team when a service goes down.
* Low Resource Footprint: Optimized for high performance and minimal overhead.
* B2B Focused: Designed for critical enterprise systems.

### Installation
```bash
npm install @tavardt/pulse
```

### Usage
```bash
npx @tavardt/pulse monitor --url https://your-service.com --webhook https://discord-webhook-url
```
